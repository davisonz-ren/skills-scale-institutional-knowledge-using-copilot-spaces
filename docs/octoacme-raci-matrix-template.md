# OctoAcme — RACI Matrix Template

## Purpose
The RACI matrix clarifies roles and responsibilities for project activities and deliverables. It ensures accountability and prevents confusion about who should do what.

## RACI Definitions

- **R — Responsible**: The person(s) who do the work to complete the task
- **A — Accountable**: The person ultimately answerable for the correct completion (only one per task)
- **C — Consulted**: People whose opinions are sought (two-way communication)
- **I — Informed**: People who are kept up-to-date on progress (one-way communication)

## Best Practices

1. **One Accountable per activity**: Ensure each task has exactly one "A" to avoid confusion
2. **Minimize Consulted roles**: Too many "C"s can slow decision-making
3. **Right-size Informed**: Share updates broadly without overwhelming stakeholders
4. **Review regularly**: Update the RACI as the project evolves and roles change
5. **Clarify ambiguity**: If two people think they're accountable, resolve it immediately

## Customization Guide

To create your own RACI matrix:

1. **List activities**: Start with project phases and key deliverables
2. **Identify stakeholders**: List all roles involved in your project
3. **Assign RACI codes**: Work through each activity and assign roles
4. **Validate with team**: Review with all stakeholders to ensure agreement
5. **Document exceptions**: Note any special cases or shared responsibilities
6. **Update as needed**: Revisit when roles change or new activities emerge

## Common Pitfalls to Avoid

- **Too many Accountables**: Leads to confusion and finger-pointing
- **No clear Responsible**: Work doesn't get done if no one is responsible
- **Everyone is Consulted**: Creates bottlenecks and slows progress
- **Forgetting to Inform**: Stakeholders are surprised by decisions
- **Not updating**: RACI becomes outdated and loses value
